Detailed Description

An interface for an audio sample.

Member Function Documentation

◆ getChannel()

SampleChannel osu.framework.audio.sample.ISample.getChannel ( )

Retrieves a unique playback channel for this sample. Multiple channels can be retrieved and played simultaneously, but can only be heard up to getPlaybackConcurrency() times.

Returns
The unique SampleChannel for the playback.

Implemented in osu.framework.audio.sample.Sample, and osu.framework.audio.sample.SampleVirtual.

The number of times this sample (as identified by name) can be played back concurrently. This affects all ISample instances identified by the same sample name.

◆ play()

SampleChannel osu.framework.audio.sample.ISample.play ( )

Creates a new unique playback channel for this sample and immediately plays it. Multiple channels can be played simultaneously, but can only be heard up to getPlaybackConcurrency() times.
