Detailed Description

An interface which can be bound to other IBindables in order to watch for value and disabled changes.

Parameters
<T>The type of value encapsulated by this bindable.

Binds this bindable to another such that bi-directional updates are propagated. This will adopt any values and value limitations of the bindable bound to.
